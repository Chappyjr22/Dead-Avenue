copied from `Chappyjr22/zombie-town-updated` at commit
`8ac866712cffd023e6a6fb1336ce841c243e862c`, `assets/models/weapons/cc0/`.

Source pack: https://3dmodelscc0.itch.io/free-cc0-guns-explosives-pack
License: CC0 1.0 Universal; see `LICENSE.txt`.

All models have embedded resources. No separate texture files or Godot import
metadata are needed. `manifest.json` records sizes, checksums, and model counts.
The existing Makarov remains at `../makarov.glb`. The multipart M1911 is excluded.

These are source assets only, not new selectable weapons. Before integration,
check each model's forward axis, component seating, scale, hand sockets, muzzle,
and ADS alignment. Authored orientation varies between models. No transforms
or animation conversions have been applied during this import.
